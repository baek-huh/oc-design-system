Renders any of the 229 OC icon glyphs (icon/ic-* set, outline + fill variants) from icon-data.js; paints with currentColor.

```jsx
const { Icon } = window.OCDesignSystem_0d42ed;
<Icon name="IconIcHomeFillFalse" size={24} style={{color:'var(--slate-900)'}} />
```

Names: see Icon.d.ts. `FillFalse` = line, `FillTrue` = solid; arrows use `SmallFalse/SmallTrue` (24 vs 16 artboard).
