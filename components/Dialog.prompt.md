Modal dialog with title, contents and actions.

```jsx
const { Dialog } = window.OCDesignSystem_0d42ed;
<Dialog  />
```

Props:
- `showTitle`: boolean
- `showContents`: boolean
- `text1`: string
- `text2`: string

Text layers are exposed as `text1…textN`; icon/slot layers as `icon1…iconN` (ReactNode).
